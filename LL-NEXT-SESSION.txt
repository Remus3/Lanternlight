HOW TO WRITE THE NEXT HAND-OFF
Draft it into a scratch file, then run:
  python ops/handoff.py --from-file <draft> --target C:/Lanternlight/LL-NEXT-SESSION.txt

a refusal leaves the previous hand-off byte-unchanged and exits 1. There is no
exemption list and no override flag: if a legitimate hand-off is refused, the

written that way, which is the only live proof that path works.
