THE TRANSFERABLE RULE: any sweep for a value is a claim about that value's
CONTIGUITY. The cheapest way to defeat one is to write the value in a form the
language rejoins and the reader rejoins and the sweep does not - concatenated
literals, a wrapped line, an interpolation, a list of characters, two
variables. When you need to refer to a value that must not appear, refer to it
by DESCRIPTION and put the concrete probe in a test with a synthetic value.
