THE HEADER FINDING, worth carrying into any future sweep
  An orphaned EMPTY directory is reported by exactly ONE of the enumeration
  commands in common use, because git does not report empty directories.
  `git status --ignored --porcelain` does not list it. `git status --porcelain
  --untracked-files=all <path>` returns nothing. `git check-ignore -v <path>`
  exits 1 saying only that no rule matches, which is an answer about
  .gitignore. Only `git ls-files --others --directory` sees it.
  AND THE COMMAND USUALLY RECOMMENDED MISSES ONE. Measured with both orphans
  present: `--others --exclude-standard --directory` reported .backtest/ and
  NOT .claude/worktrees/; without --exclude-standard it reported both; scoped
  with `-- .claude` it reported nothing while pathlib confirmed the directory
  existed. So the guard enumerates with `--others --directory` and applies
  .gitignore per path afterwards.
