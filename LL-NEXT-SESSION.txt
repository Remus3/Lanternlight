=== FIVE THINGS THIS SESSION LEARNED THE EXPENSIVE WAY ===

1. A MODULE'S OWN GREEN IS NOT THE WORK BEING DONE. tests/test_gitignore_
   shadowing.py passed 19 of 19 while the SUITE was red. A new tracked test
   module ALSO needs a row in docs/INVENTORY.md, an owner in ops/lanes.py, and
   its lane contract regenerated with `python scripts/write_lane_contracts.py`.
   Three places, none visible to the module's own run.

2. PROSE IS A CODE CHANGE, and tests/test_source_register.py is where you find
   out. Writing a ROADMAP or ledger entry that names a git CONFIG KEY
   (core.excludesFile), a dotted METHOD CALL (env.pop), a Windows EXECUTABLE
   (find.EXE) or a SPECIMEN FILENAME (notes.txt) reddens that guard, because the
   host-shaped pattern reads every dotted tail as a domain. Each was looked at
   and registered in KNOWN_NON_HOSTS. Never add a real host there to make a red
   run green.

3. A FILED CLAIM IS A HYPOTHESIS EVEN WHEN IT IS THIS REPOSITORY'S OWN. OPS-83
   said the hook body calls "find, grep, head, mv, printf, tr and wc". Measured:
   `mv` appears ZERO times, and `find` appears only inside `--find-renames` - a
   hyphen is a word boundary, so a naive scan read a git FLAG as a utility. The
   real gate is `sh`: without it git cannot spawn the hook at all.

4. A NAME-ONLY PRESENCE PROBE LIES ON WINDOWS. With Git's usr\bin stripped,
   shutil.which("find") returns C:\Windows\system32\find.EXE and which("sort")
   returns system32\sort.EXE. Programs wearing POSIX names on a box with no
   POSIX userland.

5. THE INSTRUMENT IS PART OF THE MEASUREMENT, twice in one session. A mutation
   harness reported a false SURVIVED because two mutants of equal byte length
   written in the same second let pytest replay a cached .pyc - purge
   __pycache__ and run -B. And tools/false_red_probe.py run from a worktree
   inside the system temp tree reported its control UNPROVEN, counted its own 5
   control tests as repository tests, and still printed a full count table that
   read exactly like findings. Run it from the real tree.
